# 🎯 Quiz Game

An interactive and responsive **Quiz Game** built using HTML, CSS, and JavaScript. Test your knowledge with multiple-choice questions, get instant feedback, track your score, and view your final performance through a clean and user-friendly interface.

## ✨ Features

- 📝 **Multiple-Choice Questions** — Answer questions across different general knowledge topics.
- ✅ **Instant Feedback** — Identify correct and incorrect answers.
- 📊 **Real-Time Score Tracking** — Monitor your score as you progress.
- 📈 **Progress Bar** — Track your progress throughout the quiz.
- 🏆 **Performance-Based Results** — Receive feedback based on your final score.
- 🔄 **Restart Quiz** — Play again and try to improve your score.
- 🎨 **Clean UI** — Enjoy a simple, attractive interface with a warm color palette.
- 📱 **Responsive Design** — Adapt the layout for smaller screens and mobile devices.

## 🛠️ Technologies Used

- **HTML5** — Structures the quiz interface.
- **CSS3** — Styles the interface with layouts, colors, transitions, and responsive design.
- **JavaScript** — Handles quiz logic, answer validation, score calculation, and navigation between screens.

## 📸 Project Preview

The quiz interface includes a question display, multiple answer options, a score indicator, and a progress bar for an engaging quiz experience.

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash

```

### 2. Navigate to the Project Folder

```bash
cd Quiz-Game
```

### 3. Run the Application

Open `index.html` in your preferred web browser.

No additional dependencies or installations are required.

## 🎮 How to Play

1. Open the application in your browser.
2. Click **Start Quiz** to begin.
3. Read each question and select your answer.
4. Receive visual feedback for the correct answer.
5. Track your score and progress as you answer questions.
6. View your final score and performance message.
7. Click **Restart Quiz** to play again.
